  追踪逻辑：
  1. HSV 颜色空间掩码 → 形态学去噪
  2. 找最大轮廓 → 计算质心坐标
  3. 换算为协议帧：X偏移、Y偏移、距离（面积估算）、置信度
  4. 通过串口以 ~12Hz 发送 6 字节帧给 STM32
  5. 同时监听 STM32 反向命令（LEARN/CLEAR/STOP）

  树莓派上运行：
  pip install opencv-python pyserial numpy
  python color_tracker.py
  # 或指定参数
  python color_tracker.py --port /dev/ttyAMA0 --camera 0 --no-serial  # 测试模式

  数据流：
  摄像头 → OpenCV HSV检测 → 找最大色块
      → 计算 x_offset/y_offset/distance/confidence
      → 串口 [0xA5, X, Y, D, C, XOR] → STM32 USART2
      → control.c MODE_VISION 处理 → PID转向+速度

  需要调整追踪灵敏度的话，修改
  HSV_RANGE（色相容差）、SAT_MIN（最低饱和度）这几个常量即可。测试模式下加上
  --no-serial 可以在 PC 上先验证追踪效果。
